# Ghanaian Cultural Lexicon (GCL)

## Version 0.1 — Validated Pilot Release

An open research resource documenting Ghanaian language, culture, and culturally situated meanings in structured, machine-readable form.

This release is based on the project's validated master workbook and represents the first public pilot release of the Ghanaian Cultural Lexicon

### Repository
- `data/GCL_v0.1.xlsx` — canonical working/release workbook
- `data/GCL_v0.1.csv` — main lexicon in tabular format
- `data/GCL_v0.1.json` — machine-readable JSON
- supporting CSV files — other validated workbook sheets

### Principles
- Preserve linguistic and regional variation.
- Document context, not just translation.
- Distinguish cultural description from interpretation.
- Record sources and uncertainty.
- Keep validation status explicit.

### Version
GCL v0.1 is the first validated pilot release.
